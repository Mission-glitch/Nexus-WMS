# Nexus WMS Enterprise Pro (Full-Stack & SQLite Architecture)

ระบบบริหารจัดการคลังสินค้าและหน้าร้าน Amazon Storefront รูปแบบ Full-Stack พร้อมระบบจัดเก็บข้อมูลถาวรด้วย **SQLite** และการซิงค์ข้อมูลระหว่างอุปกรณ์แบบ **Real-Time ผ่าน WebSocket**

---

## 🌟 จุดเด่นที่ได้รับการพัฒนาปรับปรุง

1. **สถาปัตยกรรม Full-Stack แยกไฟล์เป็นระเบียบ (Modular Structure)**
   - แยกโค้ดหน้าบ้าน (Frontend: HTML, CSS, JavaScript ย่อยตามโมดูล) และหลังบ้าน (Backend: Node.js Express Server) ออกจากกันอย่างชัดเจน ไม่กองรวมในไฟล์เดียว
2. **จัดเก็บข้อมูลลงฐานข้อมูลถาวร (Persistent SQLite Database)**
   - จัดเก็บสต็อกสินค้า, คำสั่งซื้อ, ประวัติการจัดส่ง, รายชื่อพนักงาน และรอบงานหยิบ (Waves) ลงไฟล์ฐานข้อมูล `nexus_wms.db`
   - ปิดโปรแกรมหรือรีเฟรชหน้าจอ ข้อมูลไม่สูญหาย
3. **การทำงานร่วมกันแบบ Real-time ข้ามอุปกรณ์ (WebSocket Sync)**
   - เมื่อลูกค้าสั่งซื้อสินค้าจากหน้า **Storefront** รอบงานหยิบจะเด้งขึ้นหน้าจอคนหยิบสินค้าทันที
   - เมื่อพนักงานหยิบของโดยสแกนผ่าน **มือถือ/Handheld** หรือกล้อง หน้าจอโต๊ะแพ็ก (Put-Wall) และแดชบอร์ดจะอัปเดตแบบสดๆ ทันที
4. **รองรับอุปกรณ์พกพาในคลังสินค้า (Mobile & Barcode Gun Ready)**
   - ใช้งานผ่านเบราว์เซอร์บนมือถือได้ทันที พร้อมระบบสแกนด้วยกล้องหรือปืนยิงบาร์โค้ดไร้สาย

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```text
c:\Users\user\Desktop\Anew\

└── public/                   # โฟลเดอร์สำหรับ Frontend
    ├── index.html            # โครงสร้างหน้าเว็บหลัก สะอาดและแยกส่วน
    ├── css/
    │   ├── style.css         # CSS หลักสำหรับระบบ WMS, ป้ายไฟ Rack, ตาราง และหน้าพิมพ์
    │   └── amazon-store.css  # CSS หน้าร้าน Amazon Storefront และ Cart
    └── js/
        ├── api.js            # Client สื่อสารผ่าน REST API & WebSocket Real-time
        ├── store.js          # ระบบหน้าร้าน สั่งซื้อ ตะกร้าสินค้า
        ├── picking.js        # สถานีหยิบสินค้า (Zone Picking Hub, S-Shape, ไฟเชลฟ์)
        ├── pack.js           # โต๊ะแพ็ก (Put-Wall), พิมพ์ใบสั่งงาน (Pick Slip), ปิดกล่อง
        ├── barcodes.js       # ป้ายบาร์โค้ด EAN-13 และ QR Code พร้อมพิมพ์
        ├── analytics.js      # แดชบอร์ดวิเคราะห์สถิติ (Chart.js) และ ABC Analysis
        ├── worker.js         # ระบบเข้ากะ-ออกกะพนักงาน และคำนวณ UPH
        ├── inbound.js        # สถานีรับเข้าสินค้าและเพิ่ม SKU ใหม่
        └── app.js            # ควบคุมการทำงานหลัก, การเปลี่ยนหน้า และระบบเสียง
```

## 🚀 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์ (ง่ายที่สุด)
- ดับเบิ้ลคลิกที่ไฟล์ `start.bat` ในโฟลเดอร์นี้
- โปรแกรมจะเปิดหน้าต่างเซิร์ฟเวอร์และเปิดบราวเซอร์ไปที่ `http://localhost:3000` ให้อัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / Command Line
```powershell
# รันเซิร์ฟเวอร์แบบปกติ
npm start

# หรือรันแบบ Dev Watch (รีโหลดอัตโนมัติเมื่อแก้โค้ด)
npm run dev
```

## 📱 การเชื่อมต่อจากมือถือหรือ Handheld Scanner ในคลัง

1. ตรวจสอบให้มือถือและคอมพิวเตอร์เชื่อมต่อ **Wi-Fi วงเดียวกัน**
2. ดูหมายเลข IP ของเครื่องคอมพิวเตอร์ (ตัวอย่างเช่น `192.168.1.50`) ซึ่งจะแสดงบนหน้าต่างเซิร์ฟเวอร์
3. เปิดเบราว์เซอร์บนมือถือแล้วพิมพ์:
   ```text
   http://192.168.1.50:3000
   ```
4. สามารถเปิดหน้า **สแกนหยิบ (Picking)** หรือ **รับเข้า (Inbound)** เพื่อใช้กล้องมือถือสแกนบาร์โค้ดสินค้าได้ทันที

## 🛠️ รายละเอียด API Endpoints (Backend REST API)

| Method | Endpoint | รายละเอียด |
|---|---|---|
| `GET` | `/api/products` | ดึงรายการสินค้าทั้งหมดพร้อมพิกัดสต็อก |
| `POST` | `/api/products/inbound` | รับเข้าสินค้าใหม่ หรือเพิ่มจำนวนสต็อกเดิม |
| `GET` | `/api/orders` | ดึงรายการคำสั่งซื้อที่กำลังดำเนินการ |
| `POST` | `/api/orders` | บันทึกคำสั่งซื้อใหม่ พร้อมสร้างรอบงานหยิบ (Wave) อัตโนมัติ |
| `POST` | `/api/orders/:id/pack` | ตรวจนับและปิดกล่องคำสั่งซื้อ พร้อมคำนวณ Lead Time |
| `GET` | `/api/orders/history` | ดึงประวัติคำสั่งซื้อที่จัดส่งเรียบร้อยแล้ว |
| `GET` | `/api/waves` | ดึงรายการรอบงานหยิบประจำโซนที่ยังไม่เสร็จสิ้น |
| `POST` | `/api/picking/scan` | ประมวลผลการยิงสแกนบาร์โค้ด ตัดสต็อก และนับชิ้นงาน |
| `GET` | `/api/workers` | ดึงรายชื่อและสถิติการทำงานของพนักงาน |
| `POST` | `/api/workers/clock-in` | บันทึกเวลาเข้ากะของพนักงาน |
| `POST` | `/api/workers/clock-out` | บันทึกเวลาออกกะของพนักงาน |
| `GET` | `/api/analytics` | ดึงข้อมูลสรุปสำหรับแดชบอร์ดและสถิติ ABC |
